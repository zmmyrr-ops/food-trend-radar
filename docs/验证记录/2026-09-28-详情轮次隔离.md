# 详情轮次隔离与全池扫描完成

此前规则/门店按钮只按商品 ID 读取最近快照，在本轮待补采时可能展示旧轮次资料。页面虽然标记采集时间，仍容易被当作当前价格的依据。

现在前端查询携带品牌 ID，接口只读取该品牌当前完整基线里的商品及相同轮次的规则/门店。价格快照过期、未来时间、商品本轮未见、详情早于价格或晚于当前时刻，均不返回当前证据。缺失不回退旧记录。卡片 key 加入轮次，新轮次到来时重置已展开内容。规则对比统一通过同券条件比较功能，不再把最新两条不相干轮次当作对比。

兼容性：不带品牌 ID 的原接口仍用于历史诊断；产品页面均使用带品牌 ID 的当前证据查询。

验证：81 项测试及类型、格式、生产构建通过。独立数据库测试涵盖旧轮次排除、跨品牌基线隔离、本轮未见、过期、未来详情和详情早于价格。未将测试记录写入运行库。

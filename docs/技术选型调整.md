# 技术选型调整

按2026年9月20日最新要求，前端采用 React，后端采用 Node.js，统一使用 TypeScript，采用 npm workspaces 管理。

原始 TDD 中 Python API、FastAPI 和 Celery 为之前的建议方案，保留原文件作为设计依据。本项目以 React + Vite、Node.js + Express 为实施基线；未来调度与模型推理优先采用 Node.js 兼容方案，具体选型在实现前评估。不因采用 Node.js 而改变PRD中的概率校准、标签、时间安全与合规要求。

目前交付范围为项目初始化。数据库、采集器、训练流程、正式预测、身份验证和通知均未实现。

# 规则结构化第一版

新增 rule-structure-v1，业务后端自动执行，不依赖大模型或人工录入。

- 从明确句式提取购买后有效天数；冲突或否定/例外句式保持未知。
- 从明确不可用日期项识别星期、连续星期范围和节假日名称。节假日具体日期仍保留原文，不擅自扩展到所有年份。
- 解析明确 HH:mm—HH:mm 时段，跨日标记；带例外文字或非法时间不直接当可用时段。
- 保留套餐项目、数量/单位和选择组，不把任选组简单相加或把菜品数量当用餐人数。
- 资格、费用、购买和预约限制保留来源文字；未知资格不等于所有人可用，未报费用不等于零。
- 分类标记两次规则快照的内容变化；忽略规则顺序变化，不把变化本身当作优惠提升。

新规则落库包含结构化结果，旧快照由读取 API 即时按当前版本解析，不触发额外上游请求。页面新增规则自动识别摘要和分类变化提示；原文继续保留。

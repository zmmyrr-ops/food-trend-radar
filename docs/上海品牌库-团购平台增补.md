# 上海品牌库：团购平台资料增补

采集日期：2026-09-20。

## 本轮结果

从大众点评公开检索资料补入43个去重品牌，启用候选从261个增至304个。43个品牌及上海门店证据已同步至系统。分店不重复计作品牌，品牌别名参与查重。

本轮重点补齐常见连锁，门店证据涉及街道、社区、交通站点及多个商圈，不限定单一商场。尚不能声称上海16区及所有品类完整覆盖。

新增全部待复核，原有157个目录资料核验记录保持原状态。数据库含1条原有停用重复记录，共305条，启用304条、待复核147条。平台检索索引可能滞后，不代表当前营业已确认。

## 实测获取边界

- 大众点评上海美食总目录在浏览器实测跳转登录，未跑通全市分类分页批量采集。
- 公开检索可获得部分上海门店名称、品类、位置及原链接。本轮属于公开索引资料采集，不是直接平台API接入。
- 部分页面团购价格隐藏并要求App查看，未将菜单推荐价作为团购价，没有录入销量、有效优惠或热度。
- 奈雪丰尚国际、颛桥万达及泸溪河沪亭北路等记录显示关门，未用这些门店作为新增品牌证据。排除了检索混入的外地门店。
- 这是一次基础品牌资料收集，不是已建立持续自动采集能力。

## 后续覆盖要求

品牌发现按上海全市和品类组织，商场目录作为补充。品牌是监测对象，门店是上海经营证据；一个品牌多家门店不能重复计数。仍需补齐遗漏常见品牌、郊区及非商场证据。区级位置没有明确证据时不推算；不从一家门店推断全市门店数。目录资料、当前经营和动态因子接入分别验收。

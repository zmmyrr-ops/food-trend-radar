# 选题机会闭环（数据尚未齐备）

本次围绕自动选题完善产品，而不是继续增加人工录入入口。

## 已实现

- `/api/v3/selection-board` 提供真实变化候选、品牌过滤、类型/关注/忽略过滤、分页及全池新鲜/可比基线计数。自动排除停用品牌、身份冲突和过期记录。首次建库与重建基线不会被当作刚上架。
- 票面降价：显示上次价格、当前价格、少付金额及降幅；资格、门店和规则有缺口时保留待核验。排序采用线索类型、降幅、节省金额和发现时间，不标为概率或已核验推荐。
- 同价列示增量：按两轮同名同单位套餐项检查数量仅增不减；要求同期完整规则/门店、其他返回规则与店域一致、票面固定价格相同。缺少单位、套餐替换/减少、选几或新增限制无法按增量线索处理。对应原文和具体数量变化可查看。
- 即使列表字段未变，后台规则对比识别的套餐/限制变化也可进入机会榜。
- `PUT /api/v3/selection-board/:product/disposition` 保存关注/暂不考虑/恢复。按品牌与券隔离，证据版本变化返回 409 避免误操作；新价格或规则版本会重新展示忽略的券。月售数字变化不单独触发重新出现。关注券无新变化时只进入关注筛选，不重复作为扫描摘要里的新线索。
- 完整轮次自动生成一次站内摘要，最多显示 10 条线索；与已核验机会提醒分开，后者原有门槛保持。摘要形成时仍缺规则的券可能在后续补采后进入实时机会榜，摘要不伪称最终完整报告。
- 规则/门店任务优先采集有变化的券，每四次保留一次普通队列任务；仍用全局串行门控，结束后等待 1—2 秒。
- 上海天气按未来 72 小时实际覆盖预报小时分日显示温度范围、最高小时降雨概率及节假日；12 小时过期或未来观察记录不冒充当前天气。
- 首页置顶机会榜；券列表不再重复显示无区分度的 0—89.5 分。详细评分历史仍保存未知区间和依据。

## 验证边界

使用独立内存数据库和虚构测试券验证变化分类、过滤、操作持久化、版本冲突、提醒幂等；没有向生产数据库写入测试优惠。真实数据是否出现可比机会由实际两轮采集决定，空榜不会填充示例。

尚未完成：达人同券覆盖和品牌指数授权来源、全量店域、复杂权益和品牌身份核验、品类天气影响校准、7 天连续运行验收。系统现在能输出“值得继续核验的选题线索”，不能承诺“已确认值得拍的抢跑榜”。这些不是页面或打分公式可以替代的数据。

## 价格不变误入机会榜修复

用户指出 47→47 等卡片仅销售截止时间变化。此前将列表 TERMS_CHANGED_UNVERIFIED 全部视为机会线索，分类过宽。现改为仅真实降价、首次发现、同价列示增量或详情对比识别的套餐/规则变化可进入机会榜；纯标题、销售截止时间、平台状态更新保留原始记录，不再作为机会。

首次发现只显示“当前价格”，规则变化且价格相同显示“价格未变”，不再用箭头制造降价印象；规则变化不再提示可能增加权益。新增回归覆盖普通信息更新排除，以及确实降价同时截止时间变化仍保留风险提示。77 项测试通过。

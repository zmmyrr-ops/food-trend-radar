# 代金券条款比较与秒级使用时段

## 问题与实现

平台代金券可能返回有效期、适用商品、费用及使用限制，却没有套餐菜品列表。此前将完整套餐与条款比较绑定，导致已有条款无法比较。

现在在同品牌同券的两轮可比快照中，分别判断条款文字和完整套餐证据。条款具备正确轮次及采集时间时，可以展示具体文字差异；文字相同仅标记“返回条款文字相同”，不等同完整权益一致。完整套餐、门店与价值门槛没有放宽。缺少上一轮条款时继续未知，来源删除字段也不解释为取消限制。

使用时段支持 HH:MM:SS，保留秒精度并校验范围；跨午夜及混合精度按完整时间比较。自然语言例外继续标记未解析。

## 验证

格式、类型、83 项测试及生产构建通过。新增用例涵盖无套餐的条款变更、相同条款、证据时间不合格、完整权益仍未知，以及全天、跨午夜、混合秒精度和非法时段。

本机部署和真实接口验证结果见执行日志。达人及品牌指数输入仍缺失，本次不宣称已获得完整优惠推荐或爆款概率。

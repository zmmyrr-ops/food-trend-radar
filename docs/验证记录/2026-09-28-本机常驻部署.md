## 后续更新操作

先构建源码。暂停采集并确认请求已排空后，执行：

```sh
node scripts/local-service.mjs stop
node scripts/prepare-local-runtime.mjs
node scripts/local-service.mjs install
node scripts/local-service.mjs status
```

健康检查通过后恢复采集。prepare 脚本会保留上一运行副本，不能在服务占用数据库时执行。install 健康检查失败会卸载并禁用启动项，不把失败当部署成功。本部署配置使用本机默认 3001 端口，不是公网或多实例方案。

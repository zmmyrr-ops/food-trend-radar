# 上海美食优惠券机会雷达 V3

React + Node.js，上海范围，复用现有品牌池。当前主线：自动采集优惠券 → 完整快照 → 历史对比 → 观察榜；后续接入同券达人饱和度、平台指数、天气节假日，再综合评分。旧爆款概率主流程已停用。

## 当前本机服务

已安装 launchd 常驻服务时，直接访问 http://127.0.0.1:3001 。不要同时执行下面的开发启动命令，避免与同一数据库的服务冲突。可用 `node scripts/local-service.mjs status` 检查服务。

## 启动

使用 Node.js 22.12+：

```sh
nvm use
npm install
npm run dev
```

开发前端 http://localhost:5173 ，后端 http://127.0.0.1:3001 。

```sh
npm run check
npm run build
npm start
```

构建后访问 http://127.0.0.1:3001 。PGlite 数据持久化在 `data/postgres`。同一个数据目录只能由一个服务进程访问。当前限本机使用，尚无生产权限系统。

## 当前功能

- 当前选品查询为上海、美食、不限直播/短视频；旧的仅直播口径已修正。
- 所有启用品牌可一键排队，单请求串行，前一个请求完成后随机等待 1—2 秒；进程启动首个请求至少等待 2 秒。
- 上海 00:00 / 12:00 调度，按时段去重；默认关闭，可在页面开启。服务需持续运行；重启仅补当前时段。
- 分页检查点、完整快照事务提交、品牌级失败隔离、授权或限流全局暂停。网络中断及 502/503/504 最多重试两次，分别至少等待 5 秒、10 秒；授权和限流不自动重试。
- 每次请求记录开始、完成、间隔与结果，页面可检查轮次审计；旧轮次无追溯记录。
- 观察榜每页 50 条，支持翻页；覆盖明细区分召回和名称匹配。
- 商品大整数 ID 无损保存，金额按分；首次基线、首次观察、价格变化和其他字段变化分别展示。
- 关键词召回与品牌归属分开，名称匹配仅为线索；券规则缺失时价格变化不直接认定更优惠。
- 自动汇总平台品牌 ID 候选和归属冲突；券卡片展开可查看票面变化、上海门店证据及权益缺口。
- 基线超过 36 小时或查询口径变化时重建，跳过差异推断；“本轮未见”只展示历史信息，不认定下架。
- 默认首页为优惠券观察榜。未接通的达人、指数、天气与规则明确显示缺失，暂不生成综合分。

## 授权配置

服务读取本地 `data/secrets/douyin-headers.json` 的授权请求头（cookie、x-secsdk-csrf-token 等），仅向固定抖音选品接口发送。文件不提交 Git；目录建议 0700、文件 0600。前端和日志不输出凭据。文件存在不代表授权仍有效；失效会停采，更新授权后在页面恢复。

### 2026-09-28 更新

名称配置变化会自动触发一次复查，品牌诊断区分过期、待复查和实际召回状态；当前补采与历史累计分别展示。全池扫描可补齐运行中的局部任务，仍全局串行。

macOS 常驻部署脚本：`node scripts/local-service.mjs install|status|stop`。安装前需停止当前实例；脚本健康检查失败会卸载并禁用启动项。常驻部署现已完成，采用 Application Support 中的独立运行副本，源码 data 链接至唯一业务数据目录。更新前停止服务，执行 `node scripts/prepare-local-runtime.mjs` 再安装；详见 [常驻部署记录](docs/验证记录/2026-09-28-本机常驻部署.md)。

采集调度已调整：每 5 个成功列表页穿插一次规则/门店补采，两类补采轮换；列表结束后继续处理剩余补采。所有请求仍共用串行门控，完成后等待 1—2 秒，避免全池扫描期间补采一直得不到执行。全池列表完成时间会相应延长。

## 选题工作台（2026-09-28）

机会榜支持券名/品牌搜索、最低降价金额和比例，以及不同排序。每分钟刷新。下方跨券比价按真实列示套餐及返回条款比较不同券 ID，以上轮同组最低价作参照，不使用相似标题猜测完整权益。

“选题简报与跨券比价”提供全品牌 Markdown 下载；下载为当前未忽略线索，不跟随上方临时搜索条件。后台每分钟保存 `data/reports/selection-brief-current.json`、`selection-brief-current.md`、`stability-current.json`。这些文件不含登录凭据。

连续运行验收检查最近 14 个已结束定时时段；验收器已实现，不表示已经连续运行 7 天。当前达人覆盖、品牌指数、完整权益及品牌身份仍有缺口，不输出伪造的爆款概率。

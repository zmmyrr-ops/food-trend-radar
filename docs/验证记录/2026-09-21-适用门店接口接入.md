# 适用门店接口接入验证

2026-09-21。本次实现商品详情 → 门店 ID → 门店详情的自动采集链路。

## 接口与边界

- 商品范围：`/life/alliance/v2/goods/product/detail/get`，读取 `poi_count`、`poi_id_list`。
- 门店明细：`/life/alliance/v1/goods/product_info/poi_list/get`，传入 `product_id` 和 JSON 编码的 `poi_id_list`；每批最多 20 个 ID。该返回无分页标志，按声明 ID 分块核对。
- v2 门店路径曾返回重定向；v1 未传 ID 列表曾返回参数错误。补齐已知参数后取得成功响应，不需要跨域传递登录凭据。
- 城市名为上海市且行政区划码符合 310xxx 才标记上海证据。仅存门店名称、ID、城市、区划码、地址与区名，不存电话和签名图片。
- 声明数量与唯一 ID 数不符、零门店、超过 1000 个 ID、明细缺失均标记不完整；不推断其他门店。超过 1000 的保护上限待后续完善。
- 异常 ID 或结构、鉴权、限流停止采集；网络错误有限重试。与现有队列共用串行门控，请求结束后等待 1–2 秒。过时基线任务跳过。

## 实测

牛New 9 张券入队，4 张完整、5 张不完整。商品 1876640352505867 返回 1 家且核对一致：牛New寿喜烧(华润时代广场店)，上海市浦东新区，行政区划码 310115。

其余 2,735 张名称匹配券已入队，总计 2,744 张。此数为任务数，不代表已完成。入队时健康接口近 24 小时 3,737 次请求，短于 1 秒间隔为 0。后续以运行页面计数为准，需本地服务保持运行。

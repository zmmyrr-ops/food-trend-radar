## 01 当前目标与判定规则

当前主线：上海品牌池 → 每日 00:00 / 12:00 自动采券 → 比较价格/权益变化 → 计算每张券的月售净增速度、加速度和自身历史倍数 → 排序、核验与导出。

用户已明确放弃内容竞争方向：不分析达人饱和度，不因视频多少扣分，不把月售当作内容竞争指标。品牌指数与天气为辅助信息；没有可用来源或验证依据时保持未知，不阻塞基础销量热度榜。

- [x] 产品方向确认：关注券成交热度提升速度，无须日常人工录入，业务后端即可执行，不依赖大模型。
- [x] 技术栈与范围：React + Node.js；上海；309 个候选品牌、308 个启用，超过 150—200 个品牌的最低目标。
- [x] 采集约束：全局串行，每次请求结束后随机等待 1—2 秒；翻页、重试、详情/门店均共用门控。

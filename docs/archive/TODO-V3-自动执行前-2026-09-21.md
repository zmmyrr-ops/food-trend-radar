# 上海美食优惠券机会雷达 开发待办 V3

日期：2026-09-20。当前唯一主线：每日两次优惠券变化监测 → 性价比 → 同券达人饱和减分 → 品牌热度 → 天气节假日 → 机会评分。旧八因子、p72、抢跑指数、逐品牌官网调查不再驱动执行顺序。技术栈 React + Node.js，城市上海，沿用 308 品牌候选。

## 执行约束

- 每日 Asia/Shanghai 00:00、12:00 触发，不是每 12 小时漂移执行。
- 全局并发为 1；每个请求结束后等待随机 1—2 秒。搜索、详情、翻页、重试、补采和手动运行共用门控。
- 限流或风控延长等待或停采；禁止靠多账号、多代理绕过。间隔不构成不封号保证。
- 所有启用品牌都创建任务；失败、无券、部分页和误匹配分别统计，不伪装成完整覆盖。
- 只用上次成功完整快照作基线。首次建立基线不等于上新，关键词召回不等于品牌归属。
- 日常不依赖人工录入。授权失效时允许用户重新登录；数据暂缺不编造。
- 本清单 [x] 只代表对应范围已验证；已有基础代码是否可复用需检查，不视为 V3 已实现。

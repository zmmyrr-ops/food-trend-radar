# 跨时段排队与恢复修复

2026-09-29，已部署本机服务并恢复原采集队列。

发现：start 在有运行轮次时直接合并触发，新的自然时段无法立即形成独立轮次。另有去重返回后不唤醒已有任务的边界。

修复：自然时段 slot 唯一且独立建轮；旧轮次未结束时新时段排队，由同一个 worker 按轮次顺序执行，不并发。手动触发仍合并到最早轮次。定时调用去重后仍唤醒未完成工作；不会重新采集已完成轮次。

完整检查：121 项测试、类型检查和生产构建通过。新增测试在首轮请求被阻塞时触发第二时段，验证两轮两任务、时段去重、手动合并、最大并发 1，最终基线来自第二轮；另验证 worker 重建后由 schedule 继续同一时段任务，不建重复轮次。

本机部署后状态见同名 JSON。未在生产伪造中午时段或重置旧轮次。自然跨时段的实测尚待发生；迟到完成依然无法通过原 14 时段验收器，排队不等于准点完成。

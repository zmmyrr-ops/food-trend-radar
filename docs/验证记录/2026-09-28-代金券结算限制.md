# 代金券结算限制识别

## 已实现范围

从已采集的使用条款中识别完整明确句式：列示适用范围、兑现/找零/转赠、其他优惠同享、不可抵扣的费用、超券面补差价，以及已支持的称重结算复合句。复合句必须全文匹配，不能从带例外的句子中摘词推断。

每项包含原文、来源规则字段、结构化值；不同声明标记冲突，相关但未解析的原文保留。API 的 structured.voucher 返回这些字段，当前券详情新增“代金券抵扣与补差价”摘要和逐项展开原文。既有两轮原文比较继续识别规则变化。

小程序订单的费用抵扣排除只用于该渠道；不可抵扣不是已知附加费金额。没有从商品标题推断券面金额，没有据此计算完整价值或提高机会评分。

# 上海美食优惠券热度雷达 · PRD V4

更新：2026-09-29。文件名保留以兼容链接；旧版正文见 archive。完成状态以根目录 TODO 为准。

## 1. 目标与用户

帮助上海美食创作者自动发现优惠变化，以及月售展示净增快、正在加快的券。无需每日人工录入，不依赖大模型。现有 309 品牌、308 启用；品牌池不等于平台全量覆盖。

## 2. 业务流程

每天上海时间 00:00、12:00 调度启用品牌 → 串行分页采集 → 完整品牌快照提交 → 与上轮完整基线比较 → 补采权益与门店 → 热度计算 → 页面、简报与导出。

请求结束后随机等待 1—2 秒，全局并发为 1，翻页/重试/详情/门店共用门控。授权与限流异常暂停。部分轮次不能覆盖完整基线。超 36 小时或查询口径变化重建基线。

## 3. 核心功能与页面

- 优惠变化榜：首次发现、历史再现、价格补全、票面降价、规则变化等分别展示；仅截止时间变化不视为优惠提升。同价变化必须有权益依据。
- 券核验：套餐、购买资格、退款、预约、费用、结算及门店证据。完整性不足时只展示线索，不认定性价比改善。
- 月售热度榜：速度、加速度、自身历史倍数及采集时间排序；品牌、关键词、增长状态及最低净增/速度筛选。直接查看券规则和门店。
- 简报：全品牌净增速度 Top 10、优惠变化和跨券比价分别展示；JSON/Markdown 下载与自动落盘。Top 10 不受优惠线索的忽略状态影响。
- 关注/暂不考虑：优惠线索状态持久化，实质变化重新进入待看；版本过期拒绝写入。
- 运行健康：当前及历史补采、错误、间隔、品牌召回、基线新鲜度、14 时段稳定性验收。

## 4. 数据与字段

来源为用户授权的抖音选品列表、商品详情和门店接口；天气与 2026 上海日历仅作背景。品牌指数尚未接通。达人数据不再采集或参与判断。

每条券关联本地品牌 UUID、平台品牌 ID、商品 ID（字符串）、轮次、采集时间、标题、金额（分）、月售原文、规则及门店快照。名称匹配是归属线索，不等于品牌身份认证。字段缺失保留未知。

## 5. 热度与判断口径

只解析整数月售展示；万、加号与缺失不估算。速度＝月售差值/间隔小时；间隔须为 1—36 小时，当前样本须新鲜。负变化保留，可能来自滚动窗口、退款或统计口径变化，不解释为负订单。

加速度＝相邻速度差/两个窗口中点间隔；至少三点，相关窗口负净增时不算。自身倍数以排除当前窗口的连续历史速度中位数为基准，至少四窗口覆盖 24 小时，最多七天/16 点；零基准保持未知。完整品牌扫描中未见此券时保留缺失节点，禁止跨缺失节点计算。查询签名或券名变化停止对应窗口比较。标题不变的实际套餐变更仍待核验，见 TODO P1-3b。

V4.2.sales-evidence 保存原始热度与权益证据，不将速度随意换算成 0—100 分。旧 V3 评分只作历史，不参与当前排序。当前缺少校准和结果标签，不输出未来 72 小时爆款概率或抢跑概率。

优惠与热度分别呈现：销售快不证明更划算；降价不证明正在热销。权益未知不阻塞可计算的热度，但阻塞已核验优惠推荐。

## 6. 提醒与缺失规则

现有完整扫描站内摘要和已读状态保留。V4 不触发旧综合分自动推荐。热度专属告警的阈值、去重、冷却和真实样本验收列入 P2。未知不补零，首次发现不宣称刚上架，本轮未见不宣称下架。

## 7. MVP 与验收

已交付范围：串行定时采集、完整快照、优惠线索、规则/门店补采、热度榜、历史证据、筛选导出、简报、常驻和备份。每项具体证据见 TODO。

待验收：真实加速度/基准历史、月售统计地域与窗口、连续性边界、补采积压和完整性、真实正反优惠样本、连续七天自然调度。不得用合成数据完成生产验收。

## 8. 非功能、回测与后续里程碑

本机单实例，前端刷新读取本地数据，不增加平台请求。凭据不出现在页面/日志；备份可恢复；失败可暂停续采。电脑关闭或休眠期间不承诺执行，无公网多用户权限。

P0：移除达人依赖、统一热度证据/简报和文档。P1：真实数据连续性、统计口径和采集质量。P2：确定可取得的结果标签，时间切分回放（不使用未来数据），报告误报/漏报后校准阈值与提醒。P3：指数、天气影响、长期运行验收。所有未验收项目保留在 TODO，不宣称模型准确率。

### 同名券权益连续性（2026-09-29）

V4.2 将各样本所属轮次的规则快照与月售记录关联。两端规则完整、指纹非空、规则在列表采集之后 36 小时内取得，且上轮详情不晚于下轮列表时，才比较套餐/条款指纹。返回内容不同则阻断相应速度、加速度或历史基准窗口。

证据不足时，月售展示净变化仍可独立计算，但 content_comparison=unknown，不宣称同权益连续增长；same_returned_content 仅表示已返回信息相同，不代表完整权益核验。页面及 CSV 均展示该区别。指纹变化也可能来自条款或列示顺序调整，当前保守截断，不推断销量重置。真实平台统计定义仍待确认。

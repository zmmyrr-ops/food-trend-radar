# 评分与当前证据一致性

## 问题

补采结果落库与分批评分之间存在时间差。此前机会榜和评分排序只要求评分属于当前轮次，可能暂时沿用新证据到达之前的规则一致判断。重算优先队列只监测本轮详情，遗漏上轮证据更新。

## 实现

统一证据关联及匹配条件，核对基线比较状态、上一券轮次、两轮价格观察时间、两轮规则与门店快照时间。时间按数据库和 JSON 共有的毫秒精度比较，空值也必须一致，证据删除会失效旧判断。只核对最新评分，不能回退更老评分。

机会榜失效旧评分但保留真实票面降价线索；条件变化或增量判断必须等待匹配证据的重算。评分排序排除待重算项。历史评分 API 仍保留审计记录。上轮详情更新时间纳入优先重算，继续每四批一次普通轮转，避免长期排队。

## 验证

扩展现有集成用例，87 项测试及格式、类型、生产构建通过。独立数据库模拟：原同条件判断在新门店证据到达后立即失效，降价优先级回到普通线索；评分排序暂时移除，重算后恢复；删除证据再次失效。上轮补采更新在未评分普通券之前优先处理，且不产生有效推荐提醒。

真实服务部署结果见执行日志。本次不新增上游请求、不改采集节奏，不宣称达人及指数来源已接通。

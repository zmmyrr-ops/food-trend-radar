# 工作台布局整理

用户要求：界面信息杂乱，优化整体UI与布局。

## 已实施

- 桌面采用固定顶栏与左侧导航；移动端采用横向导航。
- 雷达分为优先选券、AI精选、采集管理、原始快照四个互斥视图，首页不再堆叠后台操作与原始券列表。
- 概览采用真实品牌启用数量、采集进度、状态、上海天气日历；读取中展示占位，不将未加载误报成未开启。
- 优先券卡突出票面起价、月售净增速度及优先分，保留非概率和适用性待核验提示。完整分项、品牌指数、原始月售和使用条件移到展开区域。
- AI卡片显示品牌、推荐理由与选题；整体判断、风险与数据局限折叠，原始事实与生成时间保留。
- 品牌筛选放到当前券列表/管理工具上方；保留搜索、排序、导出和分页。
- 删除旧管理页中失效的目标200与达人指数缺失概览，保留实际品牌与数据管理功能。

## 验证

前端 lint、TypeScript 与完整构建通过。浏览器验证1440px桌面双列卡片、390px手机单列，document宽度与viewport均390px，无页面横向溢出。牛New搜索返回4张优先券，9张全部券；AI原有报告正常展示；管理视图可见扫描记录，原始快照视图可见优惠券观察。

仅发布前端静态资源，未重启后端、未改变采集频率，未额外触发DeepSeek付费生成。

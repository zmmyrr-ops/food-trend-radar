# 探好店 · 上海吃喝玩乐优惠雷达

React + Node.js，上海范围，覆盖餐饮品牌、亲子乐园、主题乐园、动物海洋馆、展馆观光、户外景区和运动玩乐。当前主线：自动采集优惠券 → 完整快照 → 历史对比 → 观察榜；计算月售净增速度、加速度和历史倍数。达人竞争已退出；综合分未校准，不输出爆款概率。

## 当前部署

生产入口：https://tanhaodian.cn/ ，使用独立访问账号。ECS 通过 systemd 常驻运行；本机采集服务已停止并禁用登录自动启动，避免重复请求平台。部署、备份和回滚说明见 [ECS 运维文档](deploy/ecs/README.md)。本机开发请使用独立测试数据，不要启用生产采集凭据。

## 启动

使用 Node.js 22.12+：

```sh
nvm use
npm install
npm run dev
```

开发前端 http://localhost:5173 ，后端 http://127.0.0.1:3001 。

```sh
npm run check
npm run build
npm start
```

构建后访问 http://127.0.0.1:3001 。PGlite 数据持久化在 `data/postgres`。同一个数据目录只能由一个服务进程访问。后端仅监听本机地址；生产通过 Nginx HTTPS 和整站 Basic Auth 访问，尚无多用户角色权限系统。

## 当前功能

- 采集优先处理历史已有品牌匹配的任务；首次发现查询查满三页仍无名称匹配且没有历史有效匹配时，停止继续翻页并记为 `NO_BRAND_MATCH`（未完整、待核验）。保留已采集证据，不更新基线、不推断下架。有当前或历史匹配的品牌继续完整分页；下一轮会重新查询待匹配品牌。
- 工作台分别展示已处理、完整采集、待核验数量，以及当前品牌和已查询页数。已处理不等于完整采集。

- 当前选品查询为上海、美食、不限直播/短视频；旧的仅直播口径已修正。
- 所有启用品牌可一键排队，单请求串行，前一个请求完成后随机等待 1—2 秒；进程启动首个请求至少等待 2 秒。
- 上海 00:00 / 12:00 调度，按时段去重；跨时段独立排队，由同一 worker 顺序执行；默认关闭，可在页面开启。服务需持续运行；重启仅补当前时段。
- 分页检查点、完整快照事务提交、品牌级失败隔离、授权或限流全局暂停。网络中断及 502/503/504 最多重试两次，分别至少等待 5 秒、10 秒；授权和限流不自动重试。
- 每次请求记录开始、完成、间隔与结果，页面可检查轮次审计；旧轮次无追溯记录。
- 观察榜每页 50 条，支持翻页；覆盖明细区分召回和名称匹配。
- 商品大整数 ID 无损保存，金额按分；首次基线、首次观察、价格变化和其他字段变化分别展示。
- 关键词召回与品牌归属分开，名称匹配仅为线索；券规则缺失时价格变化不直接认定更优惠。
- 自动汇总平台品牌 ID 候选和归属冲突；券卡片展开可查看票面变化、上海门店证据及权益缺口。
- 基线超过 36 小时或查询口径变化时重建，跳过差异推断；“本轮未见”只展示历史信息，不认定下架。
- 默认首页为优惠券观察榜。月售热度独立排序；指数及未核验规则明确显示缺失，不生成未校准综合分。

## 授权配置

服务读取本地 `data/secrets/douyin-headers.json` 的授权请求头（cookie、x-secsdk-csrf-token 等），仅向固定抖音选品接口发送。文件不提交 Git；目录建议 0700、文件 0600。前端和日志不输出凭据。文件存在不代表授权仍有效；失效会停采，更新授权后在页面恢复。

## AI 综合推荐（DeepSeek）

首页点击「生成 AI 推荐」。后端从新鲜候选券选取最多40张、每品牌最多3张，发送优惠变化、月售速度/加速度、可用品牌指数和上海天气日历摘要，由 DeepSeek 返回最多5张推荐券、选题角度、待核验项与局限。候选与时间范围会明确展示，AI 不覆盖算法分，不输出爆款概率。仅点击时调用付费 API；同时只允许一次分析，60秒冷却，90秒超时，不自动重试。失败保留旧结果，超过12小时标注旧建议。

后端优先读取环境变量 `DEEPSEEK_API_KEY`，否则读取 `data/secrets/deepseek.json`。本机 launchd 不继承交互 shell 的 `.zshrc`，可运行：

```sh
node scripts/configure-deepseek.mjs
```

脚本只读取 `.zshrc` 的 `DEEPSEEK_API_KEY` 字面量或当前环境变量，不执行 shell 配置，将密钥保存至忽略版本管理的数据目录（0600）。更新密钥后重新运行即可，后端每次请求重新读取。不要将密钥写入 `VITE_` 变量。平台 Cookie 与登录头不发送给 DeepSeek。

接口：`GET /api/v3/ai-recommendations` 查询配置状态/任务状态/最近成功结果；`POST /api/v3/ai-recommendations`，JSON `{}` 启动分析，返回202；冷却时返回429。分析结果与原始候选证据存储在本机 `ai_coupon_reports`。券名等来源文本按不可信输入处理；服务端拒绝候选之外或重复的券ID、非JSON及截断输出。生成文字仍属于AI判断，不能替代完整权益核验。

接入依据：[DeepSeek Chat Completions 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)，使用 `deepseek-flash`、非思考模式和 JSON 输出。

## 小红书实况素材

优先选券卡片下展开“小红书实况素材”，点击“获取资源”后，按券的品牌和名称调用搜索及详情接口。每次最多检查 20 篇笔记、读取 2 页搜索结果、保留 40 个去重后的实况资源；数量不足时如实展示。只有明确标记 `live_photo=true` 且具有受支持 CDN 视频地址、正文或标题包含品牌/别名的内容才入选。属于相关探店参考，不代表已核实同券；不参与优惠券评分。

小红书独立全局串行队列，请求完成后间隔 3–5 秒；重复点击复用任务，成功结果和已读取笔记缓存 4 小时。授权错误暂停该凭据的后续请求，更新凭据后恢复；限流/网络错误至少冷却 10 分钟。服务重启后的未完成任务标记中断，避免自动重复大量请求。已获取内容保留，可点击停止任务。视频仅在点击播放后加载，媒体链接失效时可查看原文。

后端凭据文件为私有 `data/secrets/xiaohongshu-requests.json`，内容为两个请求模板的数组，每项包含 `url`、`headers`、原始 JSON 字符串 `body`。只支持 `https://so.xiaohongshu.com/api/sns/web/v2/search/notes` 和 `https://edith.xiaohongshu.com/api/sns/web/v1/feed`。Cookie、签名仅在服务端使用，不发送前端、不提交 Git；请求签名与登录态的长期有效性不作保证，失效时需更新请求模板。媒体请求不携带接口 Cookie。

接口：`GET /api/v3/coupon-media?brand_id=...&product_id=...` 读取任务；`POST /api/v3/coupon-media` 提交相同字段；`POST /api/v3/coupon-media/:id/cancel` 停止。GET 和轮询仅访问本项目数据库，不触发小红书采集。

### 优先分 v3：原价折扣

权重：销量升温30、加速度15、原价折扣25、较上次降价10、品牌指数10、环境适配10（尚未计分）。原价折扣 = 1 − 当前售价 / 平台原价；优惠比例50%及以上得25分，线性封顶。仅使用同一快照内明确的单一售价；原价缺失、低于售价、多规格或范围不完整时不计该项。平台原价是参考口径，不代表历史成交价或已核验的实际价值。缺失项不重新分配权重。已有快照包含原价即可参与，无需重新采集。

### 优先分 v4：优惠门槛

v3基础分乘优惠系数 min(1, 优惠比例 / 20%)；优惠不足10%不进入优先券及AI推荐候选，但保留在全部券。优惠证据缺失时暂不推荐，分数为0并标明证据不足。优先使用当前原价折扣，缺失时以已确认的历史降价替代；已知弱折扣不能通过历史降价绕过门槛。这些阈值为当前业务规则，尚未回测校准。示例：99元抵100元，基础分35.9，系数0.05，最终1.8分。

### AI短视频工作室

券下“制作15–20秒短视频”打开独立页面。选择已有实况或上传自有图片/视频（单文件50MB、每项目4–40个），可上传授权配乐，确认素材使用权限后自动筛选并合成。默认18秒；支持15/20秒，Flash初筛、Plus精选，素材不足不循环凑数。支持字幕、换片、起止时间和调序，720p预览、1080p MP4导出；原素材声音默认关闭。横向画面保留主体比例并以模糊背景适配竖屏，静态图轻微推近。

后端读取 `data/secrets/bailian.json` 中的 `api_key`（文件权限600，不提交）。北京地域百炼端点；模型快照 `qwen3-vl-flash-2026-01-22` / `qwen3-vl-plus-2025-12-19`。UI费用为按较高档位估算的费用，不是账单；累计模型预算1元。选择素材后会向百炼发送抽帧画面，不发送小红书Cookie。分析缓存复用内容哈希、品牌和模型/提示词版本。

需安装FFmpeg（含libass）与FFprobe，可使用锁定的npm静态二进制；支持 `FFMPEG_PATH` / `FFPROBE_PATH` 指定路径。中文字幕需Noto Sans CJK SC，可放到 `data/videos/fonts` 或安装系统Noto CJK字体。`npm run build` 后启动服务；独立媒体子进程单队列、FFmpeg单线程，数据库仍只由API持有。任务刷新可恢复，服务重启显示中断并允许重试；取消会终止同进程组的视频工具。原始素材下载串行间隔3.5秒，401/403/429不盲目重试。

已接入：项目创建/查询、素材上传、时间线修订、预览、导出、取消、鉴权下载、删除项目。入口 `/api/v3/video-projects`；反向代理上传大小需51m。文件保存在私有 `data/videos`，不自动发布。每项目最多40素材、全局50项目，磁盘少于2GB暂停新素材准备；请通过制作记录删除不再需要的项目。当前不做无人确认的定时清理，也不自动刷新过期的小红书签名。质量判断仍可能误判，请在发布前看预览并核对权益。


## 上海游玩扩展（2026-09-30）

## 账号与个人创作空间（内部测试）

服务端通过 `AUTH_TEST_MODE=true` 启用手机号 + 固定验证码 `666666` 登录，不发送短信，也不能证明手机号属于登录者。测试期间保留 Nginx BasicAuth 访问保护，不能作为公开注册方案。未启用测试模式时，登录返回短信尚未配置，不存在隐藏万能验证码入口。

- 新手机号第一次登录创建普通账号；管理员通过服务端 `AUTH_ADMIN_PHONE` 指定，不采用首位注册者自动成为管理员。
- 登录会话采用随机令牌，数据库只存令牌摘要，HttpOnly / SameSite=Strict Cookie；HTTPS 下启用 Secure，有效期 7 天。退出使当前令牌立即失效。
- 素材任务、上传文件、视频项目绑定账号。列表、详情、渲染、取消、删除、下载和素材预览均执行服务端归属检查。
- 品牌与优惠券池共享；普通账号只读浏览、获取自己的素材、制作自己的视频；采集设置、导入、来源配置等仅管理员可操作。
- 原有创作数据默认归入隔离存档，不暴露给新用户。确认管理员手机号后，配置 `AUTH_ADMIN_PHONE` 并重启，把存档迁移给指定账号；不要把别人的手机号填写为管理员。
- 本次需先确认管理员手机号再切换线上版本，避免用户暂时看不到旧作品、失去采集管理入口。账号登录不能替代现有反向代理访问保护，真实短信接入后才评估公开开放。

# 热度导出与券核验

新增按当前条件导出全部热度记录的 CSV 接口和页面链接，支持品牌、关键词、最低速度/净增、类型及排序，不受分页限制。未知值留空；长商品 ID 带文本标记，源文本公式前缀转义，逗号/引号/换行遵守 CSV 转义，保留负数。

热度卡提供当前票面起价、权益和门店核验入口，复用当前品牌完整轮次证据，不额外请求平台。页面区分计算时间与实际采集时间。

后台既有分钟任务自动保存 sales-heat-current.json、sales-heat-current.csv，原子替换、0600 权限，不依赖用户打开页面。新报告不替代历史快照，无数据删除。

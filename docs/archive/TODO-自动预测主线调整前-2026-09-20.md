# 美食品牌72小时爆款预测系统 功能开发清单

更新日期：2026-09-20。技术栈：React + TypeScript 前端，Node.js + TypeScript 后端。

最新确认范围：仅关注上海（region_code=310000）。首批目标200个独立品牌，正式品牌库验收不得少于150个；覆盖多种餐饮品类及上海本地品牌。全国活动仅在上海可参与时进入可拍推荐。详见 `docs/监测范围.md`。

本清单覆盖从项目基础结构、规则雷达到校准预测及生产运维的完整工作范围，依据 `docs/` 中的 PRD、TDD 与最新技术选型调整整理。原始 TDD 中 Python 服务相关建议不作为当前实施要求。

## 状态与使用规则

- `[x] ✅`：已经实现；仅代表该条描述的范围。
- `[ ] ⬜`：尚未完成，包括待确认、待开发、待测试和待上线。
- P0：规则雷达 MVP 必需；P1：正式概率与抢跑指数必需；P2：后续扩展。
- 勾选前须完成实现及适用验证，并在条目后补充代码、测试报告或验收记录位置。部分完成不勾选。
- 本文是开发清单，不代表已接入真实数据或已经验证预测效果。当前已完成工程基础及品牌、事件、CSV录入工作台；数据库完整模型、外部采集与预测仍待完成。具体交付和限制见 `docs/开发进度.md`。

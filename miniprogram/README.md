# 达人优选 · 微信小程序

AppID：`wxdcd4067f8d413b31`。使用原生 JavaScript / WXML / WXSS，无需额外 npm 安装。微信开发者工具导入本目录，选择该 AppID，即可编译。

## 功能

- 上海美食 / 游玩；优先券、全部券、新上、增长加快、降价、降价且升温。
- 品牌/券搜索，优先分、热度增速、加速度和时间排序，分页和下拉刷新。
- 券价格、平台原价、热度指数、使用规则与关联店铺。
- 个人品牌模糊搜索订阅、取消订阅、黑名单添加/移除；黑名单只影响优先券。
- 订阅消息列表、未读、已读、跳回品牌券列表。
- 微信订阅消息授权与后台发送；已接受授权最多尝试一条新事件，微信最终判断可用发送次数。不会把一次授权当成永久订阅。

## 服务端配置（未提供 AppSecret，真实联调待完成）

设置 `WECHAT_MINI_APP_SECRET`，或在根项目 `data/secrets/wechat-mini.json` 保存 `{"appSecret":"实际密钥"}`。该文件已由 `/data` 忽略；绝不可放入小程序、Git 或前端配置。AppID 与模板 ID 固定在服务端，客户端不能指定接收人或消息内容。

`WECHAT_MINI_STATE` 可设 `developer` / `trial` / `formal`，默认 `formal`。体验版联调时设为 `trial`。后台每分钟检查已有品牌订阅事件，只发授权之后、24 小时以内的新消息，每轮至多 5 条。发送结果落库；超时标记 unknown 不自动重发，避免重复推送。微信失败码保存在 notification-status，不记录密钥。

微信账号独立建档，与网站手机账号暂不合并。登录只保存随机会话令牌，openid、AppSecret 和 session_key 不返回客户端；session_key 不落库。会话 7 天有效，过期通过 wx.login 刷新。

## 微信平台操作

1. 公众平台设置 request 合法域名 `https://tanhaodian.cn`。
2. 确认模板 `ceAsC4n9rxFS_02B1pPJalXqPOQjorHgpmM-26NG9J8` 属于本 AppID，字段为 thing1、thing2、thing3、time4。模板标题“新商机提醒”；地区固定上海。
3. 按平台要求配置服务端调用 IP 白名单、隐私声明与实际服务类目。
4. 上传体验版，验证微信登录、授权、真实消息与落地页，再提交审核发布。没有自动上传或代替运营方提交审核。

官网当前有 Nginx Basic Auth，小程序无法使用网站密码。必须仅为 `/api/mini/` 增加反向代理入口（见根项目 deploy/ecs/tanhaodian.conf）；应用内仍严格校验微信会话，并只允许券、规则、品牌订阅和黑名单等明确列举的路径。其余网站路径保持原有保护。

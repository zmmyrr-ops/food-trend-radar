# 抖音团购在售券列表：可获取性验证

核验日期：2026-09-20。目标是现有308品牌在上海可用的当前在售团购券/代金券，不是视频里的历史促销价。

## 本轮实测

- 牛New视频 https://www.douyin.com/video/7654933629739465061 ：搜索能发现团购文案，但直接网页读取未取得商品列表。普通HTTP返回200、约72914字符脚本及空body，不能据此认定拿到券。未解析或绕过校验脚本。
- 一绪视频 https://www.douyin.com/video/7460485775772208421 ：网页阅读无可读正文；未取得商品ID、当前售价、有效期和上海适用门店。
- 浏览器自动化两次导航超时，且本机应用控制服务启动报错；这是本次工具环境限制，不能据此断言抖音浏览器端不可访问或一定要求登录。
- https://eos.douyin.com/ 可定位至本地直播专业版/livesite，但尚未登录查看选品广场，当前没有已验证的券样本。

## 两条明确区分的路线

1. 商品查询OpenAPI：官方文档要求能力申请、商家授权及商家account_id，只覆盖授权范围，不能默认查询308个任意品牌。文档还提示部分服务商查询结果不含POI，多SKU需额外接口；权限成功也不等于上海适用门店已完整取得。
来源：https://developer.open-douyin.com/docs/resource/zh-CN/local-life/develop/OpenAPI/general-capabilities/product-query/online.query

2. 团购达人选品广场：官方指南描述可选城市、搜索商家/商品、查看价格及销量等，并给出PC入口eos.douyin.com。更符合跨品牌发现需求，但登录后实际权限、覆盖、字段、批量访问和更新时延都未实测。文档列出PC资格门槛，是否仍适用于具体账号需以当前页面为准。可带货商品不等于平台全部优惠券，带货销量也不等于商品总销量。
来源：https://partner.open-douyin.com/docs/resource/zh-CN/mini-app/open-capacity/Industry/life/partner/CPS-guide

## 下一步验证与验收

等待确认是否有可访问团购达人中心/选品广场的账号；不要求用户人工录入券，也不索要密码或Cookie。
登录可用页面后，先在上海分别验证牛New、一绪、大牛、瑞幸、喜茶；每品牌检查商品列表翻页与详情，保存商品ID、标题、券类型、公开售价、补贴/新人价条件、使用期限、在售/售罄状态、适用上海门店、来源URL和采集时点。未完整可见的字段留空。
重复采集同一列表才可验证新增、降价、下架；首次发现时间不能当创建时间。拿到真实样本、确认允许的持续访问方式后再做批量适配，不先扩展空采集器。

本轮结论：确认了更合适的选品入口，但尚未抓到可验证的当前在售券列表；不能宣布308品牌抓取可行，也不能断言完全不可行。

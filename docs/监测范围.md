# 上海美食品牌监测范围

确认日期：2026-09-20。此范围替代早期“20品牌、3城市”的试点假设。

## 地域与品牌数量

- 唯一目标城市为上海，城市编码310000；界面默认上海，不要求用户选择其他城市。
- 按200个独立品牌规划，正式品牌库至少150个通过核验。采集与评分按200品牌负载验收。
- 品牌、门店、产品、别名分别管理。同一品牌不同门店或不同产品不能用于凑品牌数量。
- 全国营销动作可作为前置信号；全国热度仅作为标明地域的辅助特征，不冒充上海需求。
- 全国活动需核验上海适用门店、价格、时间与条件后进入可拍推荐。上海参与情况未知则待核验，非上海活动排除。

## 品类覆盖建议

以下为200品牌的建库配额建议，并非已核验品牌名单。允许根据实际上海可参与性调整，但须记录品类缺口。

- 茶饮与果饮：45个。
- 咖啡：30个。
- 烘焙、甜品与冰淇淋：25个。
- 汉堡、炸鸡、披萨等西式快餐：25个。
- 中式快餐、粉面与小吃：20个。
- 火锅、烧烤与烤肉：20个。
- 中餐正餐、地方菜及上海本地特色：20个。
- 日料、韩餐、东南亚餐等其他餐饮：15个。

全国连锁、区域连锁和上海本地品牌均纳入候选。建议上海本地及区域特色品牌合计至少30个；该数为建库建议，不是用户指定硬性要求。先按150个完成核验，再补齐至200个。

## 每个品牌必须维护的信息

品牌唯一ID、标准名、别名、主品类、连锁范围、上海经营或购买证据、官方信息来源、监测关键词、负责人、最近核验时间、来源覆盖与监测状态。主品类唯一，辅助标签可多选，避免统计重复。

上海证据可以是核验过的上海门店、上海配送范围或明确适用上海的官方活动。品牌知名度不能代替在上海可参与的证据。

## 运行策略

品牌全量监测与重点事件追踪分开：全体品牌持续发现公告和活动，有效事件按授权数据粒度更新。无新品的品牌不强行生成事件或预测。

人工阶段仍采用每天08:00、18:00审核队列；扩大品牌量后应按异常、新活动与证据变更排序处理，不能假设人工能每次逐项复核全部数据。上线前估算每日新增事件量和运营审核工时。

平台许可、配额、关键词数量及成本评估按200品牌进行。低频来源不可通过高频轮询伪装成小时级数据。若超过预算，透明降低非核心频率并披露有效覆盖。

## 验收

1. 品牌库不少于150个通过上海可参与核验的独立品牌，目标200个。
2. 各品类覆盖及缺口可查，品牌别名和门店去重，无虚构接入状态。
3. 上海本地指标与全国指标分别存储；全国活动的本地可参与情况可追溯。
4. 分开报告入库品牌数、具有有效数据的监测品牌数和当日推荐事件数。
5. 200品牌活动与关键词负载下，验证配额、队列和小时评分15分钟内完成；历史容量仍按2万事件、200万观测验收。
6. 品牌数量扩大不等于训练样本达标。正式概率仍需满足独立成熟事件、回测与校准门槛。

当前仅完成范围调整，品牌清单、上海经营核验及真实数据采集尚未完成。

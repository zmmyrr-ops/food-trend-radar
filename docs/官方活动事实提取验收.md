# 官方活动事实提取验收

日期：2026-09-20。

用户已确定暂不扩展品牌库，现有308个启用候选。本轮推进自动因子数据提取，复用首个麦当劳来源，不将单品牌接入说成全量覆盖。

## 实现

每轮读取官网列表，从近期可观察信号中选最新最多12条正文。详情仅允许麦当劳固定域名的新闻路径，检查robots，使用HTTPS带末尾斜线的正式地址，禁止自动跳转；保留15秒超时和2MB限制。

从正文范围提取价格/促销原文、使用限制、日期线索，保存正文哈希。年份省略时参考上海时区发布日期，跨半年不推定，无效日期丢弃。图片和相对日期暂不解析。

事实与公告一起保存到自动信号、修订和当轮分数快照。首次可见时间不回填为发布日期。详情失败保留失败状态，任务结果单独记录正文成功/失败数。前端展开公告可查看事实与出处。

## 核验

真实网络隔离数据库验收：读取1709条官网列表记录，对6条近期详情发出请求，6条正文解析成功。数据为真实网页，隔离环境品牌配置不计入运行库或覆盖统计。

格式、类型检查、10项测试和构建通过。测试覆盖导航排除、抽奖条件保留、无效日期、跨年歧义、正文风险、提取结果持久化及不变输入不重复修订。

首次运行库详情请求因网站301跳转HTTP而失败；修正为对应HTTPS正式地址后，隔离真实验收成功。运行库不绕过5分钟更新间隔，下一轮采集使用修正后的代码。

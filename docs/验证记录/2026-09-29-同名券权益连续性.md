# 同名券权益连续性保护验收

2026-09-29，已部署 V4.2.sales-evidence，恢复原采集节奏。

## 实现

月售历史关联各自轮次的套餐/条款快照。证据完整、指纹非空、采集时间合格时比较：返回内容不同则不计算跨版本速度，相同条件也用于加速度及历史基准窗口。历史详情晚于下轮列表时不当作当时权益证据。证据不足仍可计算独立月售展示净变化，但 content_comparison 明确为 unknown，不宣称同权益增长。

API 保存样本所依据的规则时间/指纹；页面和 CSV 展示权益连续性状态。当前排名仅允许 V4.2，旧记录仍可追溯。

## 验证

完整检查通过：119 项测试、零失败，类型检查及生产构建成功。测试覆盖同名套餐变更、条款变更、历史窗口中断、缺失/不完整规则、未来时间和历史详情补采过晚；数据库集成测试验证实际轮次关联与 CSV 导出。

本机 API/CSV 实测共 3108 张券，其中 1311 张已返回内容一致、1606 张连续性证据不足、191 张已返回内容变化。191 并不表示新增拦截 191 个有效热度结果，其中可能同时有时间间隔、模糊月售、券名变化等缺口。详见同名 JSON。

当前品牌核查：308 个启用品牌中 138 个有名称匹配候选、134 个平台名不同、26 个缺归属字段、10 个无召回。这是候选覆盖，不能认定只有这些品牌有券，也不能自动合并相似名字。

## 保留待办

指纹变化可来自文案、顺序或使用条款调整，不必然意味着销量统计重置；已返回内容一致也不代表完整权益相同。P1-3b 的真实语义与正反样本仍未完整验收，P1-5 品牌归属仍存在明确缺口，不标全量完成。

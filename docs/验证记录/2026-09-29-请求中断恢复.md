# 服务重启后的请求审计恢复

旧进程异常退出后，数据库可能保留 outcome=in_flight 且 finished_at 为空的请求。旧记录不代表新进程仍有活动请求，不能长期显示为进行中。

## 实现

在 server 启动取得数据库独占锁、完成迁移之后，且任何采集 worker 启动之前，把未完成请求标记为 INTERRUPTED，并记录 recovered_at。finished_at 仍为空：恢复时间不是网络请求真实结束时间，不能用于伪造请求耗时或间隔。成功和已经失败的历史记录不改；第二次执行不会重复改写恢复时间。

请求游标、任务状态、重试次数均不改动；原有断点续采继续负责重试与幂等写入。没有新增平台请求、提高频率或重置失败任务。来源诊断和运行状态页单独统计最近 24 小时的中断请求。

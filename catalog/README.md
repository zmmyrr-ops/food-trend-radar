# 上海品牌公开资料候选库

## 当前入库规则（2026-09-29 更新）

以大众点评上海美食的各分类为范围，必须确认页面选择“人气”排序；按该顺序归并同品牌门店，取前100个品牌，再要求其中至少一个已观察门店显示 `igroup` 团购标记及团购链接。无团购标记的不入选，不以第101名之后补凑。跨分类入选的品牌只保存一份。

`dianping-admission-policy-2026-09-29.json` 为分类与归并配置，`dianping-category-popularity-2026-09-29.json` 为逐页证据。运行 `scripts/select-dianping-brands.py` 串行采集，完成所有分类后使用 `node scripts/reconcile-dianping-selection.mjs` 预览，增加 `--apply` 才更新正式采集池。分类缺失、排序不明、验证页或空响应会阻止整批替换。

若网站阻断后仍需严格执行“无双条件证据不启用”，可显式使用 `--verified-prefix-only`：只纳入已连续核实的人气列表前缀中、品牌序位不超过100且有团购标记的记录，其余旧品牌停用待复核。此模式必须在结果中保留未完成分类，不能把部分名单标成全量完成；默认模式仍要求所有分类采集完成。

旧的默认列表、商场目录和搜索命中仅保留为历史候选资料，不能再作为启用依据。旧 `import-brand-expansion.mjs --apply` 已禁用。不符合本轮双条件的旧品牌停用，保留历史券和快照；页面默认展示当前采集品牌。团购标记来自大众点评，不等同于抖音有券或热卖。

## 核验边界

`directory_checked` 只表示本轮可访问官网目录列有该品牌在上海的店铺。核验人记为“Codex公开目录资料核对”，未冒充实地访店或电话核验。页面已改为“已资料核验”。无发布日期的目录仍可能滞后，拍摄前应再查营业与活动。

`historical_evidence_only` 保持待核验；`conflicting_directory` 指佬鲜纪与Yes 啫啫均被列在正大7F16，不能同时声称当前经营已确认。一人烧肉等可能是商户简称，独立品牌身份仍待复核。南粤小厨与南粤点心、小Q饭堂与智面局可能有共同经营主体，品牌层级待补充核实，不据多个门店凑独立品牌验收数。

品类为初分，茶饮、烘焙和西式快餐仍低于建议配额；当前样本偏向商场餐饮，不能代表上海全市场。第二轮已达到最低150个目录资料核验数量；完整字段与品类覆盖仍待补齐，SPEC-01不因数量达标而直接勾选。

## 重用

在运行中的本地API上执行 `node scripts/import-brand-research.mjs`。脚本新增缺失品牌、按内容幂等追加证据，不覆盖已有编辑或人工核验结论。仅新建且目录核对通过的记录写入资料核验结果。再次执行不会自动刷新经营状态，也不启动外部采集。

通过「品牌库 → 查看采集证据」查看每条的来源、地点、日期与限制。事件、库存、优惠、热度和预测均未伪造。
